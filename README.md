# 🗓️ Life Planner

เว็บแอปวางแผนชีวิต: จัดการงาน (To-Do), ปฏิทิน, ตารางเวลา และเป้าหมาย รวมไว้ในที่เดียว
เขียนด้วย HTML, CSS และ JavaScript ล้วน (ES Modules) **ไม่ต้องติดตั้งหรือ build อะไรเพิ่ม**
ข้อมูลบันทึกไว้ในเบราว์เซอร์ (localStorage)

## ✨ ฟีเจอร์

| หน้า | สิ่งที่ทำได้ |
|---|---|
| 🏠 **ภาพรวม** | คำทักทายตามช่วงเวลา, สรุปงาน/นัดหมาย/เป้าหมายของวันนี้, จำนวนวันที่ทำงานต่อเนื่อง, ไทม์ไลน์ของวันนี้พร้อมเส้นบอกเวลาปัจจุบัน, กราฟจำนวนงานที่ทำเสร็จใน 7 วันล่าสุด |
| ✅ **งาน** | เพิ่มงานด่วน (พิมพ์แล้วกด Enter, ลงท้ายด้วย `!` เพื่อตั้งเป็นงานสำคัญ), ระดับความสำคัญ, หมวดหมู่, วันและเวลาครบกำหนด, เชื่อมงานกับเป้าหมาย, ตัวกรองและการค้นหา, แบ่งกลุ่มเป็น เลยกำหนด/วันนี้/พรุ่งนี้/7 วันข้างหน้า, ลบแล้วกด "เลิกทำ" ได้ |
| 👥 **ประชุม** | การ์ด "ประชุมถัดไป" พร้อมนับถอยหลังและปุ่มเข้าร่วม (Zoom / Meet / Teams), รายการประชุมวันนี้ / 7 วันข้างหน้า / ที่ผ่านมา, หน้าต่างการประชุมที่มีผู้เข้าร่วม วาระ (ติ๊กได้) บันทึกการประชุม (บันทึกอัตโนมัติ แยกตามแต่ละครั้งของประชุมประจำ) และ "สิ่งที่ต้องทำต่อ" ที่ไปเป็นงานในหน้างาน, ปุ่มคัดลอกสรุปประชุมไปวางในแชทหรืออีเมล |
| 📅 **ปฏิทิน** | ปฏิทินรายเดือน (ปี พ.ศ.), แสดงนัดหมายและจำนวนงานในแต่ละวัน, คลิกที่วันเพื่อดูรายการของวันนั้น, ดับเบิลคลิกเพื่อเพิ่มนัดหมาย |
| 🕒 **ตารางเวลา** | มุมมองรายวันและรายสัปดาห์แบบ time-block, คลิกช่องว่างเพื่อเพิ่มนัด, **ลากเพื่อย้าย**, **ลากขอบล่างเพื่อปรับเวลา**, นัดหมายแบบทำซ้ำ (ทุกวัน / จ.–ศ. / ทุกสัปดาห์ / ทุกเดือน), สรุปจำนวนชั่วโมงที่วางแผนไว้ในแต่ละหมวด |
| 🎯 **เป้าหมาย** | ตั้งเป้าหมายตามด้านต่าง ๆ ของชีวิต, แบ่งเป็นขั้นตอนย่อย (milestones), กำหนดวันเสร็จพร้อมนับวันถอยหลัง, วงแหวนแสดงความคืบหน้า (คำนวณจากขั้นตอนย่อยและงานที่เชื่อมไว้) |
| ⚙️ **ตั้งค่า** | ชื่อผู้ใช้, ธีมสว่าง/มืด/ตามระบบ, เลือกวันแรกของสัปดาห์, สำรองและนำเข้าข้อมูล (.json), โหลดข้อมูลตัวอย่าง, ล้างข้อมูล |

**Animation:** เปลี่ยนหน้าแบบ fade, รายการค่อย ๆ ปรากฏตามลำดับ, ติ๊กถูกพร้อมเอฟเฟกต์เด้ง + ขีดฆ่า + confetti,
confetti ชุดใหญ่เมื่อเป้าหมายครบ 100%, วงแหวนและแถบความคืบหน้าค่อย ๆ เพิ่มขึ้น, ตัวเลขนับขึ้น, ปฏิทินเลื่อนเมื่อเปลี่ยนเดือน,
แถบเมนูที่ใช้อยู่เลื่อนตาม, modal (บนมือถือเป็น bottom sheet), toast แจ้งเตือน และพื้นหลังที่ค่อย ๆ เคลื่อนไหว
(ถ้าตั้งค่าระบบให้ลดการเคลื่อนไหว แอปจะปิด animation เหล่านี้ให้)

**คีย์ลัด:** `V` วางข้อความ · `N` เพิ่มงาน · `M` นัดประชุม · `E` เพิ่มนัดหมาย · `G` เพิ่มเป้าหมาย · `1`–`6` สลับหน้า · `T` สลับธีม · `Esc` ปิดหน้าต่าง

รองรับทั้งคอมพิวเตอร์ แท็บเล็ต และมือถือ (บนมือถือมีแถบเมนูด้านล่าง)

## 📋 วางข้อความ → แปลงเป็นนัด / ประชุม / งาน

วางข้อความจาก LINE อีเมล หรือหนังสือเชิญประชุม แล้วแอปจะแยกให้ว่าเป็น **ประชุม นัดหมาย หรืองาน** พร้อมวันที่ เวลา สถานที่ ลิงก์ประชุม ผู้เข้าร่วม และวาระ
ตรวจทานและแก้ไขได้ก่อนบันทึก และเตือนเมื่อเวลาชนกับนัดเดิมหรือดูเหมือนซ้ำ

- เปิดได้จาก ปุ่ม + → **วางข้อความ**, ปุ่มในหน้าประชุม, คีย์ลัด `V` หรือวาง (Ctrl/Cmd+V) ตรงไหนก็ได้ในแอป
- **Android:** หลังติดตั้งแอป กด "แชร์" ข้อความใน LINE แล้วเลือก **Planner** ได้เลย
- เข้าใจทั้งภาษาทางการและภาษาแชท เช่น "วันพฤหัสบดีที่ 19 พ.ย. 69 เวลา 13.30–16.30 น. ณ ห้องประชุม 2", "พรุ่งนี้บ่ายสอง", "ศุกร์นี้ 4 โมงเย็น", "วันจันทร์หน้า", "2 ทุ่ม", เลขไทย, "ภายในวันที่ 20 นี้"
- ข้อความหลายเรื่องในครั้งเดียว (หลายบรรทัด/หลายย่อหน้า/ตาราง) แยกเป็นหลายรายการให้
- **ประมวลผลในเครื่องทั้งหมด ไม่ส่งข้อความไปที่ไหน** (โค้ดอยู่ที่ `js/core/parse.js`)

## 🔔 การแจ้งเตือน

ตั้งค่า → **การแจ้งเตือน** → เปิดใช้ แล้วเลือกเตือนล่วงหน้า 5/10/15/30/60 นาที
- เตือนก่อน **ประชุม/นัดหมาย** (มีปุ่ม "เข้าร่วมประชุม" ถ้ามีลิงก์), **งานที่ตั้งเวลา** และ **ชวนวางแผนวันนี้** ตอนเริ่มงาน
- Planner เตือนได้ **ขณะเปิดแอปอยู่หรือเพิ่งสลับออก** (เว็บแอปทำงานตอนปิดสนิทไม่ได้ถ้าไม่มีเซิร์ฟเวอร์)
- ถ้าอยากให้เตือนแม้ปิดแอป: เชื่อม Google Calendar แล้วเปิด **"ตั้งการแจ้งเตือนใน Google Calendar ด้วย"** นัดที่สร้างใน Planner จะมีการแจ้งเตือนใน Google ด้วย แอป Google Calendar ในมือถือจะเตือนให้
- iPhone: ต้องติดตั้งแอปลงหน้าจอโฮม (iOS 16.4 ขึ้นไป) จึงเปิดการแจ้งเตือนได้

## 🌅 วางแผนรายวัน และ 🔒 ล็อกแอป

- **วางแผนวันนี้** (หน้าภาพรวมแนะนำให้ก่อน 16:00): ดูแถบเวลางานว่าช่วงไหนมีประชุม ช่วงไหนว่าง, ยกงานค้างมาทำวันนี้, เลือก ⭐ 3 งานสำคัญ
- **สรุปวันนี้** (หลัง 16:00): สรุปงานที่เสร็จ, เลื่อนงานค้างไปพรุ่งนี้ในคลิกเดียว, เตือนประชุมที่ยังไม่ได้จดบันทึก, บันทึกความรู้สึกของวัน
- **⭐ งานสำคัญ**: แตะดาวหน้างานในหน้าภาพรวม (วันละไม่เกิน 3 งาน) ตั้งเวลางานได้ในตั้งค่า (ใช้คำนวณเวลาว่าง)
- **ล็อกด้วย PIN 4 หลัก** (ตั้งค่า → ล็อกแอปด้วย PIN): ล็อกตอนเปิดแอป และเมื่อออกจากแอปนานกว่าที่ตั้งไว้, ใส่ผิด 5 ครั้งต้องรอ 30 วินาที,
  ลืม PIN ให้ล้างข้อมูลในเครื่องแล้วกู้คืนจาก Google Drive · เก็บแค่ค่า hash ของ PIN และเป็นการซ่อนหน้าจอ ไม่ได้เข้ารหัสข้อมูลในเบราว์เซอร์

## 🔄 ซิงก์กับ Google Calendar

ซิงก์สองทาง: นัดใน Google (ย้อนหลัง 30 วัน ถึงล่วงหน้า 120 วัน) จะเข้ามาในแอป นัดที่มีลิงก์ประชุมหรือมีผู้เข้าร่วมจะนับเป็น "ประชุม" ให้อัตโนมัติ
และเมื่อแก้ ลาก หรือลบนัดในแอป ก็จะอัปเดตใน Google ด้วย นัดที่สร้างในแอปหลังเชื่อมต่อจะถูกบันทึกลง Google ด้วย (ปิดได้ในตั้งค่า)

- บันทึกการประชุม วาระ และสิ่งที่ต้องทำต่อ เก็บในแอปเท่านั้น ไม่ส่งไป Google
- แอปไม่แก้รายชื่อผู้เข้าร่วม และไม่ส่งอีเมลแจ้งใคร
- การเข้าสู่ระบบมีอายุประมาณ 1 ชั่วโมง เมื่อหมดอายุ ปุ่มซิงก์ด้านบนจะมีจุดสีส้ม แตะเพื่อเข้าสู่ระบบและซิงก์อีกครั้ง

**แอปนี้ใส่ Client ID ไว้แล้ว** (`js/config.js`) แค่กดเชื่อมต่อ แต่บัญชี Gmail ที่ใช้ต้องอยู่ในรายชื่อ *Test users* ของโปรเจกต์ใน Google Cloud

**ถ้าจะใช้ Client ID ของตัวเอง:** ต้องสร้าง OAuth Client ID ของตัวเองใน Google Cloud Console (ฟรี) ดูขั้นตอนได้ในแอป: **ตั้งค่า → Google Calendar → วิธีขอ Client ID**
ช่อง *Authorized JavaScript origins* ให้ใส่ `https://saratkung.github.io` (และ `http://localhost:8080` ถ้าจะทดสอบในเครื่อง)
ใช้ได้เฉพาะเมื่อเปิดจากเว็บจริงหรือ localhost (หน้าตัวอย่างใน Claude เชื่อมต่อ Google ไม่ได้)

## 💾 สำรองข้อมูลไป Google Drive

เมื่อเชื่อมต่อ Google แล้ว ใน **ตั้งค่า → Google Calendar → สำรองข้อมูลไป Google Drive** จะสำรองงาน บันทึกประชุม เป้าหมาย และนัดหมาย
เป็นไฟล์ `Life Planner – สำรองข้อมูล.json` ใน Drive ของคุณ (อัตโนมัติเมื่อข้อมูลเปลี่ยนและทุกวัน) แล้วกด **กู้คืนจาก Drive** บนเครื่องใหม่ได้
แอปใช้สิทธิ์ `drive.file` ซึ่งเห็นเฉพาะไฟล์ที่แอปสร้างเอง และไม่ส่ง PIN ไปกับไฟล์สำรอง ต้องเปิดใช้ *Google Drive API* ในโปรเจกต์ Google Cloud ด้วย

## 📲 ใช้เป็นแอปบนมือถือ (PWA)

แอปนี้เป็น Progressive Web App ติดตั้งลงหน้าจอโฮมได้ เปิดแบบเต็มจอเหมือนแอปทั่วไป และ**ใช้งานได้แม้ไม่มีอินเทอร์เน็ต**

1. นำเว็บขึ้นออนไลน์ด้วย GitHub Pages (ดูหัวข้อด้านล่าง) จะได้ลิงก์ เช่น `https://saratkung.github.io/plannercsd/`
2. เปิดลิงก์นั้นบนมือถือ
   - **iPhone / iPad**: เปิดด้วย Safari → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
   - **Android**: เปิดด้วย Chrome → เมนู ⋮ → "ติดตั้งแอป" (หรือกดปุ่ม "ติดตั้งแอป" ในหน้าตั้งค่าของ Planner)
3. เปิดแอปจากไอคอน Planner บนหน้าจอโฮม

> ข้อมูลเก็บอยู่ในเครื่องนั้น ๆ ถ้าจะย้ายข้อมูลระหว่างคอมกับมือถือ ให้ใช้ปุ่มสำรองและนำเข้าข้อมูลในหน้าตั้งค่า
> นักพัฒนา: เมื่อแก้ไฟล์แล้วให้เปลี่ยนค่า `VERSION` ใน `sw.js` มือถือจึงจะแจ้งให้อัปเดตเป็นเวอร์ชันใหม่

## 🚀 วิธีรัน

แอปนี้ใช้ ES Modules จึงต้องเปิดผ่าน web server (ดับเบิลคลิกเปิดไฟล์ `index.html` ตรง ๆ จะใช้ไม่ได้)

```bash
# เลือกคำสั่งใดคำสั่งหนึ่ง
python3 -m http.server 8080
# หรือ
npx serve .
```

จากนั้นเปิด <http://localhost:8080>

**นำขึ้นเว็บด้วย GitHub Pages:** ไปที่ repo → **Settings → Pages** → Source: **Deploy from a branch** →
Branch: **`main`** / โฟลเดอร์ **`/ (root)`** → Save รอประมาณ 1–2 นาที จะได้ลิงก์ `https://saratkung.github.io/plannercsd/`
(หรือใช้ static hosting อื่น เช่น Netlify / Vercel ก็ได้)

### เพิ่มหน้าใหม่

ทุกหน้าเป็นโมดูลที่มีรูปแบบเดียวกัน:

```js
export default {
  id: 'notes', label: 'โน้ต', icon: 'note',
  subtitle: () => 'คำอธิบายใต้หัวข้อ',
  mount(root, { navigate }) {
    const render = () => { root.innerHTML = '...'; };
    render();
    return { update: render, unmount() {} }; // update จะถูกเรียกเมื่อข้อมูลเปลี่ยน
  },
};
```

จากนั้นเพิ่มโมดูลนี้ลงในอาร์เรย์ `FEATURES` ใน `js/app.js`

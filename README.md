# 🗓️ Life Planner

เว็บแอปวางแผนชีวิต: จัดการงาน (To-Do), ปฏิทิน, ตารางเวลา และเป้าหมาย รวมไว้ในที่เดียว
เขียนด้วย HTML, CSS และ JavaScript ล้วน (ES Modules) **ไม่ต้องติดตั้งหรือ build อะไรเพิ่ม**
ข้อมูลบันทึกไว้ในเบราว์เซอร์ (localStorage)

## ✨ ฟีเจอร์

| หน้า | สิ่งที่ทำได้ |
|---|---|
| 🏠 **ภาพรวม** | คำทักทายตามช่วงเวลา, สรุปงาน/นัดหมาย/เป้าหมายของวันนี้, จำนวนวันที่ทำงานต่อเนื่อง, ไทม์ไลน์ของวันนี้พร้อมเส้นบอกเวลาปัจจุบัน, กราฟจำนวนงานที่ทำเสร็จใน 7 วันล่าสุด |
| ✅ **งาน** | เพิ่มงานด่วน (พิมพ์แล้วกด Enter, ลงท้ายด้วย `!` เพื่อตั้งเป็นงานสำคัญ), ระดับความสำคัญ, หมวดหมู่, วันและเวลาครบกำหนด, เชื่อมงานกับเป้าหมาย, ตัวกรองและการค้นหา, แบ่งกลุ่มเป็น เลยกำหนด/วันนี้/พรุ่งนี้/7 วันข้างหน้า, ลบแล้วกด "เลิกทำ" ได้ |
| 📅 **ปฏิทิน** | ปฏิทินรายเดือน (ปี พ.ศ.), แสดงนัดหมายและจำนวนงานในแต่ละวัน, คลิกที่วันเพื่อดูรายการของวันนั้น, ดับเบิลคลิกเพื่อเพิ่มนัดหมาย |
| 🕒 **ตารางเวลา** | มุมมองรายวันและรายสัปดาห์แบบ time-block, คลิกช่องว่างเพื่อเพิ่มนัด, **ลากเพื่อย้าย**, **ลากขอบล่างเพื่อปรับเวลา**, นัดหมายแบบทำซ้ำ (ทุกวัน / จ.–ศ. / ทุกสัปดาห์ / ทุกเดือน), สรุปจำนวนชั่วโมงที่วางแผนไว้ในแต่ละหมวด |
| 🎯 **เป้าหมาย** | ตั้งเป้าหมายตามด้านต่าง ๆ ของชีวิต, แบ่งเป็นขั้นตอนย่อย (milestones), กำหนดวันเสร็จพร้อมนับวันถอยหลัง, วงแหวนแสดงความคืบหน้า (คำนวณจากขั้นตอนย่อยและงานที่เชื่อมไว้) |
| ⚙️ **ตั้งค่า** | ชื่อผู้ใช้, ธีมสว่าง/มืด/ตามระบบ, เลือกวันแรกของสัปดาห์, สำรองและนำเข้าข้อมูล (.json), โหลดข้อมูลตัวอย่าง, ล้างข้อมูล |

**Animation:** เปลี่ยนหน้าแบบ fade, รายการค่อย ๆ ปรากฏตามลำดับ, ติ๊กถูกพร้อมเอฟเฟกต์เด้ง + ขีดฆ่า + confetti,
confetti ชุดใหญ่เมื่อเป้าหมายครบ 100%, วงแหวนและแถบความคืบหน้าค่อย ๆ เพิ่มขึ้น, ตัวเลขนับขึ้น, ปฏิทินเลื่อนเมื่อเปลี่ยนเดือน,
แถบเมนูที่ใช้อยู่เลื่อนตาม, modal (บนมือถือเป็น bottom sheet), toast แจ้งเตือน และพื้นหลังที่ค่อย ๆ เคลื่อนไหว
(ถ้าตั้งค่าระบบให้ลดการเคลื่อนไหว แอปจะปิด animation เหล่านี้ให้)

**คีย์ลัด:** `N` เพิ่มงาน · `E` เพิ่มนัดหมาย · `G` เพิ่มเป้าหมาย · `1`–`5` สลับหน้า · `T` สลับธีม · `Esc` ปิดหน้าต่าง

รองรับทั้งคอมพิวเตอร์ แท็บเล็ต และมือถือ (บนมือถือมีแถบเมนูด้านล่าง)

## 📲 ใช้เป็นแอปบนมือถือ (PWA)

แอปนี้เป็น Progressive Web App ติดตั้งลงหน้าจอโฮมได้ เปิดแบบเต็มจอเหมือนแอปทั่วไป และ**ใช้งานได้แม้ไม่มีอินเทอร์เน็ต**

1. นำเว็บขึ้นออนไลน์ด้วย GitHub Pages (ดูหัวข้อด้านล่าง) จะได้ลิงก์ เช่น `https://saratkung.github.io/Planner/`
2. เปิดลิงก์นั้นบนมือถือ
   - **iPhone / iPad**: เปิดด้วย Safari → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
   - **Android**: เปิดด้วย Chrome → เมนู ⋮ → "ติดตั้งแอป" (หรือกดปุ่ม "ติดตั้งแอป" ในหน้าตั้งค่าของ Planner)
3. เปิดแอปจากไอคอน Planner บนหน้าจอโฮม

> ข้อมูลเก็บอยู่ในเครื่องนั้น ๆ ถ้าจะย้ายข้อมูลระหว่างคอมกับมือถือ ให้ใช้ปุ่มสำรองและนำเข้าข้อมูลในหน้าตั้งค่า
> นักพัฒนา: เมื่อแก้ไฟล์แล้วให้เปลี่ยนค่า `VERSION` ใน `sw.js` มือถือจึงจะแจ้งให้อัปเดตเป็นเวอร์ชันใหม่

## 🚀 วิธีรัน

แอปนี้ใช้ ES Modules จึงต้องเปิดผ่าน web server (ดับเบิลคลิกเปิดไฟล์ `index.html` ตรง ๆ จะใช้ไม่ได้)

```bash
# เลือกคำสั่งใดคำสั่งหนึ่ง
python3 -m http.server 8080
# หรือ
npx serve .
```

จากนั้นเปิด <http://localhost:8080>

**นำขึ้นเว็บด้วย GitHub Pages:** ไปที่ repo → **Settings → Pages** → Source: **Deploy from a branch** →
Branch: **`main`** / โฟลเดอร์ **`/ (root)`** → Save รอประมาณ 1–2 นาที จะได้ลิงก์ `https://<username>.github.io/Planner/`
(หรือใช้ static hosting อื่น เช่น Netlify / Vercel ก็ได้)

## 🧱 โครงสร้างโปรเจกต์ (แยกตามฟังก์ชัน)

```
index.html
manifest.webmanifest  ข้อมูลแอปสำหรับติดตั้งบนมือถือ (ชื่อ ไอคอน สี)
sw.js                 service worker: แคชไฟล์ให้ใช้งานออฟไลน์ได้
icons/                ไอคอนแอป
css/
  base.css          ค่าสี ฟอนต์ ระยะห่าง (design tokens) + ธีมมืด
  animations.css    keyframes และคลาส animation
  components.css    ปุ่ม การ์ด ช่องกรอก modal toast checkbox ...
  layout.css        โครงแอป: sidebar, topbar, แถบเมนูมือถือ
  views.css         สไตล์ของแต่ละหน้า
js/
  app.js            จุดเริ่มต้นของแอป: router, เมนู, คีย์ลัด, ธีม
  pwa.js            ติดตั้งเป็นแอป, ลงทะเบียน service worker, แจ้งเมื่อมีเวอร์ชันใหม่
  core/
    store.js        state + บันทึกลง localStorage + pub/sub + ข้อมูลตัวอย่าง
    selectors.js    คำนวณข้อมูล: นัดหมายทำซ้ำ, ความคืบหน้า, สถิติ, จัดเลนนัดที่เวลาซ้อนกัน
    actions.js      การกระทำที่ใช้ร่วมกัน: ติ๊กงาน (พร้อม animation), ลบแล้วเลิกทำได้
    constants.js    หมวดหมู่ สี ระดับความสำคัญ รูปแบบการทำซ้ำ คำคม
    utils.js        ฟังก์ชันวันที่ (ภาษาไทย / พ.ศ.), ตัวช่วยจัดการ DOM และ animation
  ui/
    icons.js        ไอคอน SVG
    modal.js        หน้าต่าง dialog / bottom sheet + กล่องยืนยัน
    toast.js        การแจ้งเตือน (มีปุ่ม "เลิกทำ")
    confetti.js     เอฟเฟกต์ confetti
    widgets.js      วงแหวน แถบความคืบหน้า checkbox segmented control
  forms/
    taskForm.js     ฟอร์มเพิ่ม/แก้ไขงาน
    eventForm.js    ฟอร์มเพิ่ม/แก้ไขนัดหมาย
    goalForm.js     ฟอร์มเพิ่ม/แก้ไขเป้าหมาย + ขั้นตอนย่อย
  features/
    dashboard.js    หน้าภาพรวม
    tasks.js        หน้างาน (To-Do)
    calendar.js     หน้าปฏิทิน
    schedule.js     หน้าตารางเวลา
    goals.js        หน้าเป้าหมาย
    settings.js     ตั้งค่า / สำรองข้อมูล
```

### เพิ่มหน้าใหม่

ทุกหน้าเป็นโมดูลที่มีรูปแบบเดียวกัน:

```js
export default {
  id: 'notes', label: 'โน้ต', icon: 'note',
  subtitle: () => 'คำอธิบายใต้หัวข้อ',
  mount(root, { navigate }) {
    const render = () => { root.innerHTML = '...'; };
    render();
    return { update: render, unmount() {} }; // update จะถูกเรียกเมื่อข้อมูลเปลี่ยน
  },
};
```

จากนั้นเพิ่มโมดูลนี้ลงในอาร์เรย์ `FEATURES` ใน `js/app.js`
